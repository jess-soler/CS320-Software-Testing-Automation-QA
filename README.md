# CS320-Software-Testing-Automation-QA

## How can I ensure that my code, program, or software is functional and secure?
I can improve functionality and security by testing against documented requirements, including valid, invalid, boundary, and exception conditions, and by using appropriate testing techniques for the risks of the system. The course emphasized deriving tests from the test basis and using testing to find defects and build confidence in software quality.

## How do I interpret user needs and incorporate them into a program?
I interpret user needs by translating requirements into specific behaviors, constraints, and test conditions.  Then, I maintain traceability between those requirements and the tests used to verify them. This was the approach I used with the Contact, Task, and Appointment requirements.

## How do I approach designing software?
I approach software design by breaking the system into manageable components, defining clear responsibilities and requirements, and designing for testability and maintainability. In this course, I learned to evaluate individual units while also considering how their behavior and changes could affect other parts of the system.
